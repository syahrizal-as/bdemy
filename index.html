Laravel Collections & JSON

Metode modern mengolah Array ala Laravel (*Object-Oriented*). Sangat berguna saat menarik data dari database, lalu mengirimnya sebagai JSON ke Frontend.

$products = collect([
    ['id' => 1, 'name' => 'Laptop', 'price' => 15000000],
    ['id' => 2, 'name' => 'Mouse', 'price' => 250000]
]);

// Manipulasi Array dengan mudah (filter harga di atas 1 juta)
$mahal = $products->filter(fn($item) => $item['price'] > 1000000);

// Konversi instan ke JSON untuk API Endpoint
echo $mahal->toJson(); 
// Hasil Output: [{"id":1,"name":"Laptop","price":15000000}]

Ekosistem PHP Modern & Composer

Era Baru PHP 8.x

PHP bukan lagi sekadar bahasa skrip sederhana. Dengan fitur seperti JIT (Just In Time) Compiler, eksekusi kode menjadi sangat cepat. Pemahaman Type Hinting (mendeklarasikan tipe data parameter dan return value) wajib dikuasai untuk mencegah bug fatal.

Composer: Dependency Manager

Dalam web modern, kita tidak lagi menulis semuanya dari nol atau mengunduh pustaka secara manual (.zip). Composer bertindak sebagai manajer paket cerdas yang mengunduh, memperbarui, dan menautkan (autoload) ribuan pustaka (*library*) yang dibutuhkan aplikasi kita.

File composer.json

Ibarat "resep masakan". File ini berisi daftar pustaka (dependencies) beserta versi spesifiknya. Jika proyek dipindahkan ke komputer lain, cukup jalankan composer install, maka seluruh lingkungan proyek akan direkonstruksi dengan sempurna.

Siklus Request (Lifecycle)

Bagaimana Laravel Merespons User?

Saat pengguna mengakses sebuah URL, aplikasi tidak langsung merespons. Alur datanya adalah:
Browser ➔ Route (Pengarah) ➔ Controller (Otak) ➔ Model (Database) ➔ View (Tampilan) ➔ Browser Pola pembagian tugas inilah yang secara formal disebut sebagai pola desain MVC.

Arsitektur Pola MVC

Model (M)

Merepresentasikan struktur data dan logika bisnis aplikasi. Model bertanggung jawab langsung berinteraksi dengan Database untuk mengambil atau menyimpan informasi.

View (V)

Merepresentasikan antarmuka visual (UI). View bertugas menerima data dari Controller dan merendernya ke dalam format HTML yang akan ditampilkan ke layar pengguna.

Controller (C)

Bertindak sebagai "Otak" atau konduktor. Controller menerima request dari pengguna, meminta data dari Model, dan mengirimkannya ke View yang tepat.

Anatomi Direktori & Artisan CLI

Struktur Folder Krusial

  • app/: Jantung aplikasi (Controllers, Models).
  • routes/: Pintu masuk lalu lintas URL.
  • resources/: Tempat berkumpulnya *Views* (Blade).
  • database/: Skema migrasi dan data seeder.
  • public/: Titik akses (berisi index.php, CSS, JS).

Mengenal Artisan CLI

Artisan adalah Command Line Interface (CLI) bawaan Laravel. Alih-alih membuat file Controller secara manual dan mengatur *namespace*-nya, kita cukup memerintahkan Artisan untuk melakukannya (Code Generation).

php artisan make:controller ItemController

Kekuatan Otomatisasi

Selain *code generation*, Artisan bertugas mengeksekusi migrasi database (migrate), menjalankan server pengembangan lokal (serve), membersihkan cache (cache:clear), dan memantau antrean (queue).

Studi Kasus: LaraStock MVP

Goal Pelatihan

Kita akan merealisasikan sebuah Minimum Viable Product (MVP) bernama LaraStock, sistem manajemen inventaris operasional untuk mendata sirkulasi barang di gudang. Fokus kita adalah mengimplementasikan fungsionalitas CRUD secara utuh dan aman.

Rancang via DrawSQL

Tabel: Categories

Menyimpan klasifikasi barang.

  • id (PK, Auto Increment)
  • name (Varchar 100)
  • description (Text, Nullable)

Tabel: Products

Menyimpan master data barang (*One-to-Many* dari Kategori).

  • id (PK, Auto Increment)
  • category_id (Foreign Key)
  • sku (Varchar 50, Unique)
  • name (Varchar 255)
  • stock (Integer, Default 0)
  • price (BigInt)

Tabel: Transactions

Mencatat log arus barang masuk/keluar (*One-to-Many* dari Produk).

  • id (PK, Auto Increment)
  • product_id (Foreign Key)
  • type (Enum: 'in', 'out')
  • quantity (Integer Unsigned)
  • notes (Varchar 255, Nullable)

Sesi Praktik 1.1: Setup & Database Core

Mari kita mulai membangun pondasi aplikasi LaraStock. Ikuti langkah teknis di bawah ini secara berurutan.

1 Inisialisasi & Konfigurasi Lingkungan

Buka Terminal, buat proyek baru Laravel, lalu atur kredensial koneksi database MySQL di file .env.

composer create-project laravel/laravel:^13.0 larastock
cd larastock

Edit file .env (Pastikan Anda sudah membuat database kosong bernama larastock):

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=larastock
DB_USERNAME=root
DB_PASSWORD=

2 Pembuatan Skema Database (Migration)

Kita akan merancang tabel categories, products, dan transactions.

php artisan make:model Category -m
php artisan make:model Product -m
php artisan make:model Transaction -m
_create_categories_table.php 
Schema::create('categories', function (Blueprint $table) {
    $table->id();
    $table->string('name', 100);
    $table->text('description')->nullable();
    $table->timestamps();
});
_create_products_table.php 
Schema::create('products', function (Blueprint $table) {
    $table->id();
    $table->foreignId('category_id')->constrained()->onDelete('cascade');
    $table->string('sku', 50)->unique();
    $table->string('name');
    $table->integer('stock')->default(0);
    $table->bigInteger('price');
    $table->timestamps();
});
_create_transactions_table.php 
Schema::create('transactions', function (Blueprint $table) {
    $table->id();
    $table->foreignId('product_id')->constrained()->onDelete('cascade');
    $table->enum('type', ['in', 'out']);
    $table->unsignedInteger('quantity');
    $table->string('notes')->nullable();
    $table->timestamps();
});
php artisan migrate

Sesi Praktik 1.2: Eloquent & Controller

Selanjutnya, kita akan merelasikan tabel yang sudah dibuat, mengisi data awal (seeding), dan membuat endpoint JSON pertama kita.

3 Konfigurasi Model & Relasi (Eloquent)

Buka folder app/Models, tentukan atribut Mass Assignment dan relasinya.

Category.php 
protected $fillable = ['name', 'description'];

public function products() {
    return $this->hasMany(Product::class);
}
Product.php 
protected $fillable = ['category_id', 'sku', 'name', 'stock', 'price'];

public function category() {
    return $this->belongsTo(Category::class);
}
public function transactions() {
    return $this->hasMany(Transaction::class);
}
Transaction.php 
protected $fillable = ['product_id', 'type', 'quantity', 'notes'];

public function product() {
    return $this->belongsTo(Product::class);
}

4 Mengisi Data Awal (Database Seeder)

Buka database/seeders/DatabaseSeeder.php untuk menyuntikkan data dummy agar tabel tidak kosong.

public function run(): void {
    $cat = Category::create(['name' => 'Elektronik']);
    $prod = Product::create([
        'category_id' => $cat->id,
        'sku' => 'ELK-001',
        'name' => 'Laptop Asus ROG',
        'stock' => 15,
        'price' => 15000000
    ]);
    
    Transaction::create([
        'product_id' => $prod->id,
        'type' => 'in',
        'quantity' => 15,
        'notes' => 'Restock awal dari gudang pusat'
    ]);
}
php artisan db:seed

5 Endpoint & Logika Pertama (Controller)

Buat rute percobaan untuk memastikan Model dan Database sudah terhubung sempurna.

php artisan make:controller ProductController 
// Di ProductController.php
public function index() {
    return Product::with('category')->latest()->get();
}

// Di routes/web.php
Route::get('/products', [ProductController::class, 'index']);

Jalankan php artisan serve dan akses http://localhost:8000/products di peramban!
Catatan: Karena kita langsung me-return Model tanpa memanggil View (HTML), Laravel akan otomatis menyajikannya dalam format mentah JSON (biasa digunakan untuk API).

Sesi Praktik 1.3: Advanced Controller (API Dashboard)

Mari demonstrasikan betapa saktinya Eloquent dan Laravel Collections dengan membuat endpoint untuk Dashboard Statistik Gudang.

6 Endpoint Statistik Kompleks

Kita akan membuat rute baru yang menampilkan total nilai aset (Harga x Stok) dan daftar barang yang stoknya sudah menipis.

php artisan make:controller DashboardController 
// Di DashboardController.php
public function stats() {
    $products = Product::all();
    
    // Menghitung total nilai aset dengan metode Collection sum()
    $assetValue = $products->sum(function($prod) {
        return $prod->price * $prod->stock;
    });

    // Mencari barang yang butuh restock (stock < 5) menggunakan filter()
    $lowStock = $products->filter(fn($prod) => $prod->stock < 5)->values();

    return response()->json([
        'total_products' => $products->count(),
        'total_asset_value' => $assetValue,
        'low_stock_alerts' => $lowStock
    ]);
}

// Di routes/web.php
Route::get('/dashboard/stats', [DashboardController::class, 'stats']);

Buka http://localhost:8000/dashboard/stats dan lihat bagaimana JSON yang dihasilkan sangat terstruktur!
