Hari 1: Fondasi Web Modern

A Teori Fundamental

Memahami arsitektur Client-Server, konsep kerja HTTP, dan analogi Frontend vs Backend. Membahas alasan krusial mengapa developer beralih dari PHP Native ke Framework Laravel, serta pengenalan mendalam pada arsitektur Model-View-Controller (MVC).

B Praktik Setup Proyek

Inisialisasi aplikasi larastock melalui Composer dan mengonfigurasi environment koneksi basis data melalui file .env.

C Database & Logika Awal

Menerapkan Migrations dan Seeders untuk skema tabel, serta menyusun rute dan logika kontroler (ItemController) untuk mengembalikan data mentah.

Hari 2: Aplikasi Web Interaktif

A Integrasi Blade Templating

Merancang layout utama menggunakan Blade Engine, memecah komponen (yield, extends), dan mengintegrasikan pustaka Bootstrap 5 agar antarmuka terlihat profesional dan responsif.

B Visualisasi Data (Read)

Mengekstraksi data stok dari basis data dan menampilkannya secara dinamis ke dalam tabel antarmuka menggunakan perulangan direktif @foreach.

C Form & Validasi (Create)

Membuat formulir penambahan inventaris yang dilengkapi dengan proteksi CSRF, validasi Form Request yang ketat, serta balasan notifikasi berhasil (Flash Messages).

Hari 3: Alur Kerja Profesional

A Effective Debugging

Simulasi penanganan error syntax melalui pembacaan Ignition Stack Trace. Teknik pelacakan alur data menggunakan dd() dan perekaman aktivitas operasional via Log Handling.

B Dokumentasi Standar

Menerapkan praktik penulisan PHPDoc Standard pada blok kode agar fungsionalitas mudah dipahami dan dipelihara oleh kolega (developer lain).

C Finalisasi MVP

Penyelesaian akhir seluruh fungsionalitas CRUD, dilanjutkan dengan sesi ulasan kode (Code Review), Q&A, serta berbagi wawasan tentang praktik terbaik (Best Practices) industri.

Wawasan Industri IT

Gambaran besar standar operasional dunia kerja tentang bagaimana perangkat lunak dikelola, diuji, dan dipelihara oleh Web Developer profesional.

Database dengan SQL

Apa itu SQL?

Bahasa standar yang digunakan untuk mengelola dan memanipulasi basis data relasional, seperti mengambil, menambahkan, atau mengubah data.

Perintah Dasar

SELECT - Mengambil data
INSERT - Menambahkan data
UPDATE - Mengubah data
DELETE - Menghapus data

Contoh Sintaks

SELECT * FROM users WHERE nama='John'

Instruksi untuk mengambil seluruh baris dari tabel 'users' di mana nilai pada kolom 'nama' adalah 'John'.

1 Definisi UAT

User Acceptance Testing merupakan tahapan pengujian akhir oleh pengguna untuk memastikan aplikasi beroperasi sesuai spesifikasi dan kebutuhan bisnis.

2 Alur Pengujian

Pembuatan skenario pengujian Pengguna melakukan validasi fitur Pencatatan hasil Perbaikan bug dan penyesuaian.

3 Contoh Skenario

Monitoring Aplikasi

Tujuan Monitoring

Memastikan performa, ketersediaan, dan keandalan sistem tetap optimal, serta mendeteksi potensi masalah sebelum berdampak pada pengguna.

Metrik Pemantauan

  • Penggunaan CPU (beban komputasi prosesor)
  • Penggunaan Memori (alokasi RAM aktif)
  • Bandwidth (kapasitas transfer data jaringan)
  • Waktu Respons (kecepatan pemrosesan permintaan)
