Dasar UI: Native CSS vs Framework Bootstrap

Native CSS (Custom Styling)

Styling dasar dapat dilakukan dengan dua cara utama: **Inline** (langsung di tag HTML) atau **External/Outline** (menggunakan file .css terpisah).

Inline Style: <h1 style="color: blue;">
External Style: .title { color: blue; }

Kenapa Bootstrap?

Bootstrap adalah framework UI terpopuler yang menyediakan ribuan class siap pakai (*pre-built*). Mengapa kita menggunakannya?

  • Kecepatan: Tidak perlu menulis CSS dari nol.
  • Responsive: Layout otomatis menyesuaikan ukuran HP/Tablet.
  • Konsistensi: Tampilan tombol, form, dan navigasi seragam di semua halaman.

Perbandingan Implementasi

Membangun tombol "Simpan" dengan gaya yang sama:

Native CSS 
<button class="btn-custom">Simpan</button>
/* Butuh 5-10 baris CSS di file terpisah */
Bootstrap 5 
<button class="btn btn-primary">Simpan</button>
/* Langsung jadi & cantik tanpa file CSS */

Transisi: Dari API JSON ke HTML View

Mengembalikan View

Di Hari ke-1, Controller kita me-return data Model yang otomatis dikonversi menjadi format JSON. Hari ini, kita akan mengubahnya menjadi return view('products.index', compact('products')) agar data tersebut disuntikkan ke dalam kerangka antarmuka HTML (Blade).

Named Routes (Penamaan Rute)

Praktik industri: Jangan pernah hardcode URL di dalam properti <form action="">. Gunakan sintaks route('products.store'). Jika struktur URL (*prefix*) proyek berubah, Anda tidak perlu mengedit file HTML satu per satu.

Route::resource()

Alih-alih mendaftarkan rute index, create, store, edit, update, destroy secara manual baris demi baris, kita bisa menggunakan Route::resource('products', ProductController::class) yang akan memetakan ke-7 aksi CRUD standar secara magis!

Integrasi Blade Templating

Konsep Layout & Komponen

Blade Engine memungkinkan kita memecah antarmuka menjadi komponen-komponen kecil yang dapat digunakan kembali secara modular. Hindari menuliskan kerangka HTML yang sama berulang kali di setiap halaman.

Direktif Utama Blade

@yield - Menentukan area dinamis (placeholder)
@extends - Mewarisi kerangka layout utama
@section - Mengisi area yang telah ditentukan 

{{-- Di app.blade.php --}}
@yield('content')

{{-- Di index.blade.php --}}
@extends('layouts.app')
@section('content')
    <h1>Halo Dunia!</h1>
@endsection

Integrasi Framework CSS

Memanfaatkan Bootstrap 5 melalui CDN (Content Delivery Network) agar antarmuka dapat terlihat profesional, proporsional, dan merespon segala jenis ukuran layar secara otomatis.

Blade Directives Lanjutan (Logic Control)

Blade menangani logika kontrol langsung di dalam HTML tanpa tag PHP yang berantakan:

@if($p->stock < 10)
    <span class="text-danger">Stok Tipis!</span>
@endif

@forelse($items as $item)
    <li>{{ $item->name }}</li>
@empty
    <p>Tidak ada data barang.</p>
@endforelse

@include('partials.navbar')

Visualisasi Data (Read)

Menghubungkan View dengan Database

Kita akan mengirimkan koleksi data inventaris barang (array of objects) dari Controller menuju ke Blade View, kemudian menyajikannya dalam format struktur tabel HTML yang mudah dibaca oleh pengguna.

Perulangan Data Dinamis

Menggunakan direktif @foreach($items as $item) untuk memproses sekumpulan data secara otomatis. Sistem akan mencetak baris tabel (<tr>) sebanyak jumlah entri barang yang ada di database.

Sintaks Echo Blade

Untuk mencetak isi variabel atau properti data ke layar, Blade menyediakan sintaks kurung kurawal ganda yang elegan dan aman dari serangan skrip silang: {{ $item->name }}.

Pagination (Halaman)

Sangat tidak efisien memuat ribuan data sekaligus. Eloquent menyediakan fungsi paginate() untuk membagi data menjadi beberapa halaman, lengkap dengan navigasi otomatis melalui $products->links().

Deep Dive: UX & Data Handling

Persistensi Input (old)

Sangat menyebalkan bagi user jika form kosong kembali setelah ada error validasi. Gunakan helper old() untuk menjaga input tetap ada.

<input type="text" name="name" 
       value="{{ old('name') }}">

Menampilkan Relasi

Jangan tampilkan category_id (angka) di tabel. Gunakan kekuatan Eloquent untuk memanggil nama kategori melalui relasi.

{{-- Di tabel produk --}}
{{ $product->category->name }}

Navigasi Aktif

Gunakan helper Request::is() untuk memberikan class active pada navbar agar user tahu mereka sedang di halaman mana.

<a class="nav-link {{ Request::is('products*') ? 'active' : '' }}">

Global Error List

Selain di bawah input, terkadang kita perlu menampilkan daftar semua error di bagian atas form untuk kemudahan membaca.

@if ($errors->any())
    <ul class="alert alert-danger">
        @foreach ($errors->all() as $error)
            <li>{{ $error }}</li>
        @endforeach
    </ul>
@endif

Eloquent & Security Best Practices

Mass Assignment Protection

Laravel memblokir pengisian data massal secara default demi keamanan. Anda wajib mendaftarkan kolom yang boleh diisi di dalam Model.

// Di Models/Product.php
protected $fillable = ['name', 'sku', 'price', 'stock'];

Route Model Binding

Keajaiban Laravel! Dengan mengetikkan Type-Hint Model di Controller, Laravel otomatis mencari data berdasarkan ID tanpa perlu findOrFail() manual.

public function edit(Product $product) {
    return view('edit', compact('product'));
}

Method Spoofing

Browser HTML hanya mendukung GET dan POST. Laravel menggunakan "spoofing" untuk mensimulasikan rute PUT dan DELETE standar RESTful.

<form action="..." method="POST">
    @csrf
    @method('PUT')
</form>

Bootstrap Pagination

Agar navigasi halaman (links) tampil cantik dengan Bootstrap 5, jangan lupa daftarkan di AppServiceProvider.php.

// AppServiceProvider.php
use Illuminate\Pagination\Paginator;

public function boot() {
    Paginator::useBootstrapFive();
}

Sesi Praktik 2.5: Delete Premium (AJAX + SweetAlert2)

Menghapus data dengan konfirmasi yang mewah dan tanpa me-refresh halaman secara kasar (menggunakan AJAX).

ProductController.php (JSON Response) 
public function destroy(Product $product) {
    $product->delete();
    
    // Kembalikan response JSON alih-alih Redirect
    return response()->json([
        'success' => true,
        'message' => 'Barang berhasil dihapus dari sistem!'
    ]);
}
Logic AJAX di index.blade.php 
{{-- Tambahkan script ini di bawah @endsection --}}
<script>
function deleteProduct(id, name) {
    Swal.fire({
        title: 'Hapus ' + name + '?',
        text: "Data yang dihapus tidak bisa dikembalikan!",
        icon: 'warning',
        showCancelButton: true,
        confirmButtonColor: '#d33',
        confirmButtonText: 'Ya, Hapus Saja!'
    }).then((result) => {
        if (result.isConfirmed) {
            // Proses AJAX menggunakan Fetch API
            fetch('/products/' + id, {
                method: 'DELETE',
                headers: {
                    'X-CSRF-TOKEN': '{{ csrf_token() }}',
                    'Content-Type': 'application/json'
                }
            })
            .then(res => res.json())
            .then(data => {
                Swal.fire('Terhapus!', data.message, 'success')
                .then(() => location.reload()); // Refresh halaman setelah sukses
            });
        }
    });
}
</script>

Sesi Praktik 2.6: Project Mastery (Advanced)

6 Pencarian & Filter Dinamis

Tambahkan input pencarian di atas tabel. Peserta harus memodifikasi Controller agar mendukung pencarian nama atau SKU.

$products = Product::when(request('search'), function($q) {

8 Advanced: Stock Transaction Log

Alih-alih mengedit stok secara langsung, buatlah sistem transaksi (Barang Masuk/Keluar). Setiap kali transaksi disimpan, stok produk akan ter-update otomatis menggunakan DB Transaction demi keamanan data.

DB::transaction(function() use ($request) {
    $product = Product::find($request->product_id);
    // Tambah/Kurang Stok
    $product->increment('stock', $request->qty);
    // Catat Riwayat
    Transaction::create($request->all());
});
